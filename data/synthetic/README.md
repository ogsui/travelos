# Synthetic data

Generated by task 007 from `travelos.synthetic.generator`. Every value is
obviously fake; do not put real agency data here.

Regenerate with `make seed` or `python -m travelos.admin.seed`. Set
`SYNTHETIC_SEED` to change the dataset (the default is `20261025`). The same
seed must produce byte-identical files; the committed `manifest.json` records
the seed, record counts and SHA-256 for each file.

Do not edit these files by hand. Change the generator and regenerate. Tests in
`tests/unit/test_synthetic_data.py` validate every record against
`data/schemas/` and fail when a file or the manifest is stale.
